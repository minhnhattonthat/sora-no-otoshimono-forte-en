# Glossary - Sora no Otoshimono Forte: Dreamy Season (Heaven's Lost Property Forte: Dreamy Season)

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (user, 2026-10-14)
- Honorifics kept, hyphenated (Sugata-senpai, Tomo-chan, Sohara-chan). Name order: given name first (Tomoki Sakurai).
- Romanisation source: Funimation anime "Heaven's Lost Property" (the manga had no English release). Hepburn without
  long-vowel marks for anything not in it (Eishiro, not Eishirou).
- Credits / staff roll: English.
- Scope: whole game in one go; plans pre-approved.
- Register: light anime-comedy fan-sub flavour; keep the ecchi gags and puns funny, not literal.
- Sound effects: in-box SFX lines (`{1F}{xx}` big text) stay short onomatopoeia: "Tweet, tweet-tweet." "Thud! Crash! Splat!"
- Abbreviations: full names and terms everywhere; the box is VWF, ~40-44 chars per line, 3 lines.

## Style rules
- Punctuation: 「」 -> "...", 『』 -> '...' (or "..." when it is a title), …… / … -> ..., ー (stretched vowel) -> repeated letter or
  "~" sparingly, ！？ -> ?!, ♪ and ☆ may stay (they are in the font), full-width space indent at line start: drop.
- Inner thoughts （…） -> keep the parentheses: (Man, this is peaceful...)
- Ikaros: flat, polite, halting ("...") speech; calls Tomoki "Master". Nymph: bratty, teasing, calls him "Tomoki".
  Astraea: dim, energetic, food-obsessed; calls him "Tomoki". Sohara: kind childhood friend, karate-chop threat; calls him "Tomo-chan".
  Sugata: dry, intense lecture mode about the New World. Mikako: sweet-voiced sadist, "ufufu"; calls Tomoki "Sakurai-kun".
  Tomoki: perverted everyman, loud tsukkomi, inner monologue in ( ).
